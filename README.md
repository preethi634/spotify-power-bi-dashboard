# Spotify Music Analytics Dashboard

## Project Overview

An interactive Power BI dashboard designed to explore Spotify music data and present insights through data visualization.

## Tools Used

* Microsoft Power BI
* Power Query
* DAX (if used in the project)

## Dashboard Features

* Music data exploration and visualization
* Analysis of available track and artist metrics
* Interactive charts, filters, and KPIs (as implemented)

## Project Files

* `Spotify_Dashboard.pbix` – Power BI report
* `dashboard-screenshot.png` – Dashboard preview

## How to View

Download the `.pbix` file and open it using Microsoft Power BI Desktop.
